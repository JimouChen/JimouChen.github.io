## 1. 为什么需要自动求导？

训练神经网络的本质是**不断调整参数，让预测更准**。调整方向由梯度（导数）决定：

```text
参数 → 计算预测 → 计算损失(loss) → 反向传播求梯度 → 更新参数 → 循环
```

如果每次都要手写导数公式，模型一复杂就写不动了。PyTorch 的 Autograd 能**自动追踪每一步运算，反向算出所有参数的梯度**。

## 2. 最小示例：一个数的求导

```python
import torch

# requires_grad=True 表示：这个张量需要计算梯度
x = torch.tensor(3.0, requires_grad=True)

# y = x 的平方
y = x * x

print(y)
# 输出：tensor(9., grad_fn=<MulBackward0>)
# grad_fn 说明：PyTorch 记住了这个数是通过"乘法"得到的

# 反向传播：计算 dy/dx
y.backward()

# 梯度存在 x.grad 里
print(x.grad)
# 输出：tensor(6.)
# 验证：y = x²，dy/dx = 2x = 2×3 = 6 ✓
```

## 3. 看懂它怎么"记账"的

```python
import torch

a = torch.tensor(2.0, requires_grad=True)
b = torch.tensor(5.0, requires_grad=True)

# 两步运算：c = a×b，d = c + a
c = a * b
d = c + a

# 对 d 求导
d.backward()

print(a.grad)
# 输出：tensor(6.)
# 手算验证：d = a×b + a
# dd/da = b + 1 = 5 + 1 = 6 ✓

print(b.grad)
# 输出：tensor(2.)
# 手算验证：dd/db = a = 2 ✓
```

这就是"链式法则"的自动化：`d` 沿着计算图反向走，把每一步的局部导数乘起来，落到每个叶子变量上。

## 4. 和神经网络的关系（预览）

```python
import torch

# 假设一个最简单的"网络"：y = w·x + b
w = torch.tensor(2.0, requires_grad=True)  # 权重
b = torch.tensor(1.0, requires_grad=True)  # 偏置
x = torch.tensor(3.0)                       # 输入（不需要梯度）

y = w * x + b  # 预测值
target = 10.0  # 真实值

# 损失：预测与真实差距的平方
loss = (y - target) ** 2

loss.backward()

print("w 的梯度:", w.grad)
# 输出：tensor(-24.)
# 手算：y = 7，y-10 = -3，loss = 9
# dloss/dw = 2(y-10)·x = 2×(-3)×3 = -24 ✓

print("b 的梯度:", b.grad)
# 输出：tensor(-6.)
# 手算：dloss/db = 2(y-10) = -6 ✓

# 顺着梯度反方向更新，loss 就会变小——这就是"训练"
```

## 5. 算出参数的梯度，意义是什么？

### 一句话版本

> 梯度指向"让损失变大最快的方向"，沿着**反方向**走，损失就下降——这就是训练的全部秘密。

### 展开讲

训练前，模型的参数（权重）是随机的，预测很烂，损失很大。我们想知道：**每个参数应该调大一点还是调小一点？调多少？**

梯度恰好回答了这个问题。对每个参数求偏导：

```text
∂loss/∂w 的含义：
"如果 w 增加一点点，loss 会变化多少？"
```

- 梯度是**正数** → w 增大会让 loss 变大 → 应该把 w **调小**
- 梯度是**负数** → w 增大会让 loss 变小 → 应该把 w **调大**
- 梯度**越大** → 这个参数错得越多，调整幅度应该越大

用本课第 4 节的例子验证：

```python
# w = 2.0, b = 1.0, y = 7, target = 10, loss = 9
# w 的梯度 = -24（负数且绝对值很大）
# 解读：w 增大会让 loss 快速下降 → 该把 w 大幅调大
```

### 参数更新的公式（所有训练的核心）

```python
w = w - 学习率 × w.grad
```

这就是"梯度下降"：顺着梯度的**反方向**，走一小步（学习率控制步长）。重复几万次，loss 一路下降，模型就"学会"了。

### 完整的梯度更新流程图

```text
┌──────────────────────────────────────────────────────────┐
│                    初始化参数（随机权重）                  │
└──────────────────────────┬───────────────────────────────┘
                           ▼
            ┌─────────────────────────────┐
      ┌────>│  1. 前向传播 forward        │
      │     │  用当前参数算出预测值 y       │
      │     └──────────────┬──────────────┘
      │                    ▼
      │     ┌─────────────────────────────┐
      │     │  2. 计算损失 loss            │
      │     │  衡量预测 y 与真实值的差距    │
      │     └──────────────┬──────────────┘
      │                    ▼
      │     ┌─────────────────────────────┐
      │     │  3. 反向传播 backward         │
      │     │  自动算出每个参数的梯度 grad  │
      │     └──────────────┬──────────────┘
      │                    ▼
      │     ┌─────────────────────────────┐
      │     │  4. 更新参数 optimizer.step() │
      │     │  w = w - 学习率 × w.grad    │
      │     └──────────────┬──────────────┘
      │                    ▼
      │     ┌─────────────────────────────┐
      └─────│  5. 清零梯度 zero_grad()      │
   重复循环  │  准备下一轮（梯度会累加）     │
            └─────────────────────────────┘
```

### 流程图每一步对应的代码（以 y = w·x + b 为例）

用最简单的线性模型走一遍完整循环：给定数据 `x=3.0, target=10.0`，目标是学出合适的 `w` 和 `b`。

```python
import torch

# ========== 初始化参数（随机权重） ==========
# 实际项目用随机初始化，这里为方便观察用固定值
w = torch.tensor(2.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)

x = torch.tensor(3.0)      # 输入数据（不需要梯度）
target = torch.tensor(10.0) # 真实值

lr = 0.1                   # 学习率（控制每次调多大）

for step in range(3):      # 只跑 3 轮，观察变化

    # ===== 1. 前向传播 forward =====
    y = w * x + b          # 用当前参数算出预测值
    print(f"第 {step} 轮预测: y = {y.item():.4f}")

    # ===== 2. 计算损失 loss =====
    loss = (y - target) ** 2   # 预测与真实的差距（平方误差）
    print(f"第 {step} 轮损失: loss = {loss.item():.4f}")

    # ===== 3. 反向传播 backward =====
    loss.backward()        # 自动算出 w.grad 和 b.grad
    print(f"  w 的梯度: {w.grad.item():.4f}, b 的梯度: {b.grad.item():.4f}")

    # ===== 4. 更新参数 optimizer.step() =====
    # 这里手写更新，等价于 optimizer.step() 的最简版本
    with torch.no_grad():   # 更新参数时不记录梯度
        w -= lr * w.grad
        b -= lr * b.grad

    # ===== 5. 清零梯度 zero_grad() =====
    w.grad.zero_()         # 不清零的话，下一轮梯度会累加
    b.grad.zero_()

print(f"训练结束: w = {w.item():.4f}, b = {b.item():.4f}")
```

运行结果：

```text
第 0 轮预测: y = 7.0000
第 0 轮损失: loss = 9.0000
  w 的梯度: -24.0000, b 的梯度: -6.0000
第 1 轮预测: y = 9.6000
第 1 轮损失: loss = 0.1600
  w 的梯度: -4.8000, b 的梯度: -1.2000
第 2 轮预测: y = 9.9920
第 2 轮损失: loss = 0.0001
  w 的梯度: -0.0960, b 的梯度: -0.0240
训练结束: w = 3.0992, b = 1.0240
```

逐行对照流程图：

| 流程图步骤 | 代码 | 说明 |
|---|---|---|
| 初始化参数 | `w = torch.tensor(2.0, requires_grad=True)` | 实际项目用随机初始化 |
| 1. 前向传播 | `y = w * x + b` | 用当前参数算预测值 |
| 2. 计算损失 | `loss = (y - target) ** 2` | 预测与真实的差距 |
| 3. 反向传播 | `loss.backward()` | 自动算出 w.grad、b.grad |
| 4. 更新参数 | `w -= lr * w.grad` | 沿梯度反方向走一小步 |
| 5. 清零梯度 | `w.grad.zero_()` | 防止下一轮梯度累加 |

观察结果的三个要点：

1. **loss 从 9 一路降到 0.0001**——这就是"训练在起作用"的直接证据。
2. **梯度也在变小**（-24 → -4.8 → -0.096）：预测越来越准，参数需要调整的幅度自然越来越小。
3. 第 4 步的 `torch.no_grad()` 是因为**更新参数本身是一次普通运算**，不应该被记进计算图；真实项目里这步由 `optimizer.step()` 代劳，不用手写。

### 放到大模型视角
- **Pretraining**：对几十亿参数求梯度，更新几十亿个权重。
- **SFT / LoRA**：只对新增的一小部分参数求梯度更新。
- **梯度消失/梯度爆炸**：训练大模型最常见的故障，本质是梯度数值太小或太大，参数无法有效更新。

Autograd 的意义在于：你只需定义好"前向计算"（怎么算 loss），它自动帮你算出几亿个参数各自该往哪调——这步如果手写，现代模型根本不可能训练。

## 6. 梯度为 0 时，预测值等于真实值吗？

### 本课例子里：成立

```python
# loss = (y - target)²
# dloss/dw = 2(y - target)·x
# 当 y == target 时：
#   loss = 0
#   梯度 = 2×0×x = 0
```

预测值等于真实值 → loss 为 0 → 梯度全为 0 → 参数不再更新 → 训练收敛。逻辑链是通的。

### 但一般情况有两个补充

**1. 梯度为 0 ≠ 一定找到了最优解**

数学上梯度为 0 只说明"到达了驻点"，驻点可能是：

```text
局部最小值 ✓（我们想要的）
局部最大值 ✗
鞍点 ✗（一个方向上是谷底，另一个方向上是山顶）
```

深度神经网络里**鞍点非常多**，训练卡住（梯度接近 0 但 loss 还很高）经常就是撞上了鞍点或平坦区。

**2. 现实中梯度几乎不会精确等于 0**

| 场景 | 实际情况 |
|---|---|
| 简单例子（y=wx+b） | 能精确收敛，梯度真的到 0 |
| 真实神经网络 | 梯度只会**越来越小**，loss 降到某个下限后就不再明显下降 |

修正后的表述：

> **预测值 ≈ 真实值 → loss ≈ 0 → 梯度 ≈ 0 → 参数几乎不再变化 → 训练收敛（也可能卡在鞍点，需警惕）。**

## 7. 鞍点和平坦区长什么样？

### 经典鞍点函数

```text
loss(x, y) = x² − y²
```

梯度为：

```python
∂loss/∂x = 2x
∂loss/∂y = −2y
```

两个梯度同时为 0 的唯一位置是 `(0, 0)`。它在原点附近的行为：

```text
沿 x 方向：loss = x²  → 像一个碗（谷底）
沿 y 方向：loss = −y² → 像一座倒扣的山（山顶）
```

所以 `(0, 0)` 就是鞍点——**一个方向上是最低点，另一个方向上是最高点**。可以拿马鞍想象：马背前后是拱起的（山顶），左右是凹下去的（谷底），人正好坐在中间的鞍点上。

### 平坦区的例子

```text
loss(x) = x³     （一维版鞍点，x=0 处导数为 0，但既非最小也非最大）
loss(x, y) = x²y²  （一大片平坦区，(0,0) 附近梯度都接近 0）
```

`x³` 在 `x=0` 处只是"歇脚点"；`x²y²` 在原点附近一整片区域梯度都接近 0，优化器走进去就会"迷路"。

### 一维鞍点"骗过"梯度下降的演示

```python
import torch

x = torch.tensor(1.0, requires_grad=True)
lr = 0.1

for step in range(20):
    loss = x ** 3 - 0.1 * x     # 在 x³ 上加个微扰动
    loss.backward()
    with torch.no_grad():
        x -= lr * x.grad
    print(f"step {step}: x = {x.item():.6f}, grad = {x.grad.item():.6f}")
    x.grad.zero_()
```

观察输出：`x` 会**越来越慢地爬向某个临界点**，梯度一路衰减到接近 0，但那个点不是最小值——这就是"训练看起来在收敛，其实卡住了"的样子。

## 8. 真实训练中靠什么逃离鞍点/平坦区？

| 手段 | 原理 |
|---|---|
| **动量 Momentum** | 梯度小时，历史速度还在，靠"惯性"冲过平坦区 |
| **Adam / 自适应学习率** | 梯度长期很小的参数自动获得更大的有效步长 |
| **mini-batch 的随机性** | 每批数据算出的梯度带噪声，恰好能把参数"晃"出鞍点 |
| **随机初始化** | 打破对称性，避免一开始就落在对称鞍点 |
| **学习率调度** | 周期性调大学习率，重新"激活"停滞的参数 |

一个好消息：**高维空间里，纯梯度下降很难精确命中鞍点**——它要求几亿个参数的梯度同时为 0，概率极低。真实的大模型训练卡住，更多是撞上"平坦区后学习率太小走不动"，所以实践中 **Adam + 合适的学习率调度**是标配组合。
